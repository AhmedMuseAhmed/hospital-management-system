# Hospital Management System

A full-stack Hospital Management System built using Next.js, Flask, and PostgreSQL.

## Features

* User Authentication (JWT)
* Login & Logout
* Protected Routes
* Dashboard Analytics
* Patient Management
* Doctor Management
* Appointment Management
* Department Management
* Search Functionality
* Charts and Reports

## Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Backend

* Flask
* Flask SQLAlchemy
* Flask JWT Extended

### Database

* PostgreSQL
